Second-year Computer Science Engineering student at Dayananda Sagar College of Engineering, Bangalore. I'm on a self-directed 90-day deep dive into ML/AI — transformers, fine-tuning (LoRA/QLoRA), tokenization, and the LangChain ecosystem — while building full-stack systems that put those concepts into production.

- 🧠 Currently studying: GPT architecture, attention mechanisms, PEFT/LoRA fine-tuning, LangChain/LangGraph

- 🐛 Contributing to open source (KubeStellar) — bug reports with clean repro steps
- 🎯 Goal: SDE / ML engineering roles — building toward placements
